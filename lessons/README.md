# Lessons

- [modal-00-baseline.toml](modal-00-baseline.toml) is the shipped, fully-calibrated modal foundations lesson covering mode entry/exit (`i`, `a`, `<Esc>`, `ctrl-[`), directional navigation (`h`/`j`/`k`/`l`), and inline diagnostic error jumping (`g ]`/`g [`).
- [motions-01-word.toml](motions-01-word.toml) is the shipped, fully-calibrated starter course lesson covering word motions (`dw`, `de`, `w` + `dw`).
- [motions-02-find.toml](motions-02-find.toml) is the shipped, fully-calibrated find-motions lesson covering intra-line delimiter navigation and operators (`df`, `dt`, `ct`, `;`, `,`).
- [motions-03-textobjects.toml](motions-03-textobjects.toml) is the shipped, fully-calibrated text-objects lesson covering delimited text objects (`ci"`, `ci{`, `ci(`) and Zed agnostic quotes/brackets, admitted under [ZK-025.3](../docs/BACKLOG.md#task-zk-025-3).
- [operators-01-edit.toml](operators-01-edit.toml) is the shipped, fully-calibrated core operators lesson covering character replacement (`r`), count multipliers (`2dw`), linewise indentation (`>>`), native surrounds (`cs`, `ds`, `ys`), and keymap contexts (`VimControl`, `vim_mode == normal`, `dev: open key context view`), admitted under [ZK-026.1](../docs/BACKLOG.md#task-zk-026-1), [ZK-026.2](../docs/BACKLOG.md#task-zk-026-2), and [ZK-026.3](../docs/BACKLOG.md#task-zk-026-3).
- [zed-01-lsp-actions.toml](zed-01-lsp-actions.toml) is the normal-mode code intelligence and language server actions module covering symbol rename (`c d`), code actions (`g .`), diagnostic navigation (`g ]`/`g [` and `:clist`), definition jumping (`g d`, `<ctrl-w> g d`), and hover documentation (`g h`), added under [ZK-027.1](../docs/BACKLOG.md#task-zk-027-1).
- [zed-02-project-panel.toml](zed-02-project-panel.toml) is the project panel and netrw navigation module covering panel focus toggling (`ctrl-shift-e`, `<escape>`), directory tree navigation (`j`/`k`, `h`/`l`, `-`), split-pane file opening (`v`, `o`), file manipulation (`%`, `d`, `R`, `D`, `ctrl-z`), and file comparison (`z d`), added under [ZK-027.2](../docs/BACKLOG.md#task-zk-027-2).
- [zed-03-multibuffer.toml](zed-03-multibuffer.toml) is the multibuffer and project search module covering project search (`g /`, `ctrl-shift-f`), match navigation (`n`/`N`), context expansion (`shift-enter`), excerpt breakout (`alt-enter`), multi-cursor editing across excerpts (`ctrl-d` + `c w`), atomic multi-file save (`ctrl-s`), and references (`g A`), added under [ZK-027.3](../docs/BACKLOG.md#task-zk-027-3).
- [zed-04-tasks-and-debugger.toml](zed-04-tasks-and-debugger.toml) is the workspace tasks and DAP debugger module covering task configuration (`.zed/tasks.json`), task variables (`$ZED_FILE`, `$ZED_STEM`, `$ZED_WORKTREE_ROOT`), task spawning (`task: spawn`, `task: rerun`, `alt-enter` oneshots), DAP debugger configuration (`.zed/debug.json`, `CodeLLDB`), pre-launch compilation tasks, gutter breakpoints (`space shift-g b`), and stepping (`F4`, `F7`, `F8`, `F9`, `space shift-g *`), added under [ZK-027.4](../docs/BACKLOG.md#task-zk-027-4).
- [zed-05-agent-panel.toml](zed-05-agent-panel.toml) is the conversational agent panel and Agent Client Protocol (ACP) module covering panel toggling (`ctrl-?`, `agent: toggle focus`), thread management (`ctrl-n`, `agent: new thread`), context mentions (`@file`, `@symbol`, `@rules`), custom ACP agent configuration (`agent_servers` in `.zed/settings.json`), stdio framing hygiene, multi-file diff reviews, and bounded context extraction, added under [ZK-027.5](../docs/BACKLOG.md#task-zk-027-5).
