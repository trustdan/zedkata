# ZK-017 TUI Shell Implementation Plan

**Date:** 2026-09-13  
**Status:** Complete. ZK-017.1 and ZK-017.2 Complete. All 100 workspace tests passing, clippy clean, fmt clean.

## Scope

Establish the Ratatui + Crossterm terminal UI for `zedkata-tui`.

## Subtasks

1. **ZK-017.1: Build the terminal shell and restore it on exit**
   - Enter raw mode and alternate screen on start; hide cursor.
   - RAII `TerminalGuard` ensures terminal restoration on normal exit or error return.
   - Panic hook via `std::panic::set_hook` guarantees terminal restoration on panic before backtrace output.
   - Event loop with key handling (`q`, `Esc`, `Ctrl-C` to quit) and resize handling.
   - Small terminal handling: if dimensions drop below 60x15, render clear warning overlay with current vs required dimensions.
   - No document-editing controls introduced (strict adherence to REQ-01 and CLAUDE.md Hard Rule 1).
   - Retain headless subcommands (`select`, `status`, `reset`).
   - Verification flags `--test-error` and `--test-panic` to confirm safe terminal cleanup.

2. **ZK-017.2: Render curriculum, task, hint and progress panes**
   - Bind curriculum catalog (`Catalog`) and session state (`SessionState`) to UI panes.
   - Vim-key navigation without mouse input:
     - `j` / `Down` and `k` / `Up` to select lessons.
     - `h` / `Left` and `l` / `Right` to navigate exercises within the active lesson.
     - `Enter` to select/activate exercise in `session.json`.
     - `?` to toggle category hint exposure.
     - `r` to refresh session and catalog from disk.
   - Status indicators: `[✓]` (completed), `[ ]` (available), `[L]` (locked), `[D]` (draft).
   - Locked lesson display: clearly explains incomplete prerequisites (e.g. `motions-02-find`).
   - Task pane: shows task description, concept list, par/max edits budget, forbid rules, hint, and Zed buffer practice path.
   - Attempt feedback & progress pane: displays live attempt verdict (Passed, Failed, InProgress, Idle), completion ratio, and recent history.
   - Responsive formatting with wrapping verified to fit within minimum 60x15 terminal dimensions.
